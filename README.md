# Area- and Power-Efficient Reconfigurable Architectures for Multi-Function Complex-Valued Computation

This repository provides RTL implementations of two independent reconfigurable hardware architectures for low-precision complex-valued function computation:

- a piecewise-linear approximation (PWL)-based architecture;
- a CORDIC-based architecture.

Both architectures use **10-bit precision** and reuse arithmetic resources to support multiple complex-valued functions in a unified hardware design.
